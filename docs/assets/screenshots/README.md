# 📸 Screenshot Drop-in Guide for Medha Landing Page

Whenever you take real screenshots of Medha on macOS, simply drop them into this folder (`docs/assets/screenshots/`) with these exact filenames:

1. **`hero-mac-app.png`**:
   - Primary hero screenshot of the full Medha application window (e.g. showing sidebar, note editor, and graph or palace view).
   - Recommended resolution: 2000px × 1250px (retina macOS screenshot via `Cmd + Shift + 4`, then `Space`, then click the window).

2. **`feature-block-editor.png`**:
   - Close-up or window capture of the hierarchical block note editor showing 740pt reading measure, headings, and active card attachments.

3. **`feature-vector-ink.png`**:
   - Screenshot of the continuous vector ink canvas with Apple Pencil or stylus handwriting, equations, and paper templates.

4. **`feature-memory-palace.png`**:
   - Screenshot of the 2D spatial memory palace walk mode showing architectural photo with numbered loci pins and walk HUD.

---
*Note: The website is already built with an automatic fallback mechanism. If any screenshot is missing, the website displays a high-fidelity macOS window wireframe with zero broken image icons.*
